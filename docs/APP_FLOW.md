## 1. High-Level User Journeys
1. **Booking Lifecycle**: Inquiry -> Date & Item Selection -> Conflict Check -> Quote / Confirmation -> Dispatch Scheduled.
2. **Dispatch & Loading**: View Daily Schedule -> Pack Equipment against Manifest -> Mark Loaded -> Mark Returned & Checked In.
3. **Conflict Resolution**: Attempted Overlap Detection -> Alert Coordinator -> Suggest Alternative Units / Dates.
